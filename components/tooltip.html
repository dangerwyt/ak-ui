Tooltip 提示 ​

文字提示，在鼠标 hover 时显示提示文字。

基础用法 ​

提供 9 种不同方向的展示方式，可以通过以下完整示例来理解，选择你要的效果。由 placement属性决定展示效果。placement属性的值为：[方向]-[对齐位置]；四个方向：top、bottom、left、right。对齐位置：start、end，默认为空。如：placement="top-start"。

<template>
  <div class="tooltip-base-box">
    <div class="row center">
      <aka-tooltip
        class="box-item"
        placement="top-start"
        content="Top Start prompts info"
      >
        <aka-button>top-start</aka-button>
      </aka-tooltip>
      <aka-tooltip
        class="box-item"
        placement="top"
        content="Top Center prompts info"
      >
        <aka-button>top</aka-button>
      </aka-tooltip>
      <aka-tooltip
        class="box-item"
        placement="top-end"
        content="Top Right prompts info"
      >
        <aka-button>top-end</aka-button>
      </aka-tooltip>
    </div>
    <div class="row">
      <aka-tooltip class="box-item" placement="left-start">
        <template #content>
          Left Top
          <br />
          prompts info
        </template>
        <aka-button>left-start</aka-button>
      </aka-tooltip>
      <aka-tooltip class="box-item" placement="right-start">
        <template #content>
          Right Top
          <br />
          prompts info
        </template>
        <aka-button>right-start</aka-button>
      </aka-tooltip>
    </div>
    <div class="row">
      <aka-tooltip class="box-item" placement="left">
        <template #content>
          Left Center
          <br />
          prompts info
        </template>
        <aka-button>left</aka-button>
      </aka-tooltip>
      <aka-tooltip class="box-item" placement="right">
        <template #content>

          prompts info
        </template>

    <div class="row">
      <aka-tooltip class="box-item" placement="left-end">
        <template #content>
          Left Bottom
          <br />
          prompts info
        </template>
        <aka-button>left-end</aka-button>

      <aka-tooltip class="box-item" placement="right-end">

主题 ​

Tooltip 组件内置了两个主题：dark和light。默认主题为dark。

<template>
  <aka-tooltip content="Top Center" placement="top" class="item">
    <aka-button>dark</aka-button>
  </aka-tooltip>

  <aka-tooltip content="Bottom Center" placement="bottom" effect="light">
    <aka-button>light</aka-button>
  </aka-tooltip>
</template>

<style scoped>
  .item {
    margin-right: 10px;
  }
</style>

更多内容的文字提示 ​

展示多行文本或者是设置文本内容的格式，可以使用具名 slot content，代替tooltip中的content属性。

<template>
  <aka-tooltip placement="top" trigger="click">
    <template #content>
      multiple lines
      <br />
      second line
    </template>
    <aka-button>more content</aka-button>
  </aka-tooltip>
</template>

Tooltip API ​

Props ​

名称说明类型默认值
content显示的内容，也可被 slot#content 覆盖string''
placementTooltip 组件出现位置enumbottom
effectTooltip 主题，内置了 dark 和 light 两种enumdark
trigger提示框的触发方式enumhover
disabledTooltip 组件是否禁用booleanfalse
manual是否手动控制Tooltip 组件booleanfalse
